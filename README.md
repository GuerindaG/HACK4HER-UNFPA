# HACK4HER-UNFPA
Maquette de prévention, d'information et d'orientation des victimes de VBG facilitées par la technologie (VBG-FT). Intégration d'un parcours SOS confidentiel avec transmission sécurisée des demandes d'assistance. Contribution à la réflexion sur la cybersécurité, la protection des données et le Privacy by Design.
